# ديارنا

تجربة محلية لاستكشاف مناطق الرياض ومكة وعسير والقصيم عبر خريطة ثلاثية الأبعاد، بالعربية والإنجليزية

https://github.com/SDAIAAcademy. 

تم تنفيذ المشروع عن طريق برنامج: "البرمجة التوليدية" من أكادمية سدايا 



الفريق:

رؤى احمد الدوسري

يارا شينان الشهراني

باسل سعد الاسمري

لما عبدالهادي الشهراني

موسى شوعي حكمي

غلا القوده

زياد ميرعالم


## التشغيل

المتطلبات: Node.js 22.12 أو أحدث وpnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

افتح العنوان الذي يظهر في الطرفية. للتحقق وبناء الإنتاج:

```sh
pnpm test
pnpm build
pnpm preview
```

## بنية المشروع

- `content/`: وثائق Word الأصلية، لم تُعدّل.
- `references/`: مراجع التصميم فقط، لا تُستخدم كصفحات أو صور للمحتوى.
- `src/data/arabic.json`: الأسماء والأوصاف المستخرجة من الوثائق.
- `src/data/english.json`: الترجمات المقابلة بنفس ترتيب العناصر.
- `src/data/assets.json`: ربط مستقل لصور العناصر والأقسام والخلفيات، مع المصادر وضبط موضع العرض.
- `src/main.jsx`: الترويسة والتنقل وقوالب المناطق والتفاصيل المشتركة.
- `src/regional-layout.css`: المقاسات المشتركة لإصلاح الصفحات الإقليمية دون تغيير الرئيسية.
- `src/SaudiMap.jsx` و`src/MapScene.js`: عرض الخريطة والطبقات والبديل الجغرافي.
- `public/`: صور وخطوط وبيانات محلية؛ لا يحتاج العرض إلى مفاتيح أو خدمات خارجية.
- `docs/`: مصادر الصور والجغرافيا وسجل الفحص.

لإضافة منطقة مستقبلًا: أضف بياناتها وترجماتها وصورها وإعدادها الجغرافي. القوالب مشتركة. لا توجد صفحات أو محتويات للمناطق التسع المستقبلية.

لم يُنشأ مستودع GitHub جديد. الربط النهائي يكون بمستودع الفريق القائم عند توفير رابطه وصلاحية الوصول إليه.
